# Changelog

## [1.0.0] - 2026-10-18

### Added

- Highlights matching shelf rows for the product box you are holding.
- Red means empty, yellow means room for more stock, and green means full. Each row uses its own capacity, including shelves with mixed rows.
- Blue marks matching storage boxes and reserved storage slots.
- Marks update when you change products and disappear when you put the box away. Existing hover effects stay intact.
- Configurable colors, storage highlights, through-wall display and refresh interval.

### Compatibility

- Works locally for each player. The host and your friends do not need the mod; it changes no stock or multiplayer state.
